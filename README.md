# Partner Statistik 2.1 – GitHub Pages

## Novinky
- Karta partnera: přidávání a odebírání zálib a nedostatků.
- Nový záznam: výběr více zálib a nedostatků, nepovinná textová poznámka.
- Historie: zobrazuje vybrané položky a poznámku. Odebrání položky z karty partnera nemaže její historické výskyty.
- Statistiky: četnost zálib a nedostatků podle vybraného období. Poznámky se do statistik nezapočítávají.
- Zůstává změna PINu, automatické zamykání, ochrana proti chybným pokusům a potvrzení importu PINem.

## Aktualizace
1. V původní aplikaci proveďte **Exportovat zálohu** a uložte JSON mimo GitHub.
2. Rozbalte ZIP a nahrajte jednotlivé soubory do kořene **stejného** GitHub repozitáře. Nahraďte soubory stejného jména.
3. Zachovejte původní URL GitHub Pages a stejné prostředí prohlížeče. Data jsou uložena lokálně v prohlížeči.
4. Otevřete aplikaci a ověřte partnery a záznamy. Pokud se nezobrazí novinky, obnovte stránku po aktualizaci GitHub Pages.

## Soukromí
PIN je zámek obrazovky; data v localStorage nejsou šifrovaná. Face ID není podporováno. Export JSON obsahuje citlivé údaje v nešifrované podobě: **nikdy ho nenahrávejte do veřejného repozitáře**.
